# Input File Requirements

This repository contains standalone research scripts. Each script has a configuration block near the top where input paths, output paths, column names, and model settings can be changed before running.

The original project data are not included in this repository. The schemas below describe the columns expected by the current scripts.

## SMFS Scripts

### `smfs/match_sfs_to_mutation_rates.py`

Matches SFS rows to mutation-rate metadata by reference context, alternate context, and methylation level.

Inputs:

| Config | Description | Required columns |
| --- | --- | --- |
| `SFS_FILE` | SFS table, read as gzipped CSV | `ref_context`, `alt_context`, `methylation_level`, `Sites` |
| `MUTATION_RATE_FILE` | Mutation-rate metadata table, read as tab-separated text | `ref_context`, `alt_context`, `methylation_level`, `mu_gnomad`, `mean_theta`, `sd_theta`, `error` |

Output:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Matched SFS table with mutation-rate metadata merged in. Written only when `SAVE_OUTPUT = True`. |

The output renames `methylation_level` to `Meth level`, `mu_gnomad` to `Mew`, `mean_theta` to `Mean theta`, `sd_theta` to `SD theta`, and `error` to `Error`.

### `smfs/estimate_lambda_poisson.py`

Estimates xi using a Poisson model with site-specific sampled mutation rates.

Input:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Simulation or site table, read as gzipped CSV from `INPUT_DIR` | `Site`, `Sampled mu`, `AC` |

Outputs:

| Config | Description |
| --- | --- |
| `OUTPUT_XI_FILE` | CSV with one column, `Lambda`. The column name is retained for compatibility with existing outputs. |
| `OUTPUT_UNIQUE_MUTATION_FILE` | CSV with expected site counts by unique-mutation count. Columns: `Unique mutation`, `Unq muts sites`. |

### `smfs/estimate_lambda_negative_binomial.py`

Estimates xi while accounting for mean and standard deviation uncertainty using a negative-binomial marginal model.

Input:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Site or SFS table, read as gzipped CSV from `INPUT_DIR` | `Sites`, `Mean theta`, `SD theta`, `AC_nfe_down` |

Outputs:

| Config | Description |
| --- | --- |
| `OUTPUT_XI_FILE` | CSV with one column, `Lambda`. Written only when `SAVE_XI_OUTPUT = True`. The column name is retained for compatibility with existing outputs. |
| `OUTPUT_UNIQUE_MUTATION_FILE` | CSV with expected site counts by unique-mutation count. Columns: `Unique mutation`, `Unq muts sites`. |

### `smfs/estimate_smfs_from_unique_mutations.py`

Numerically estimates predicted SMFS probabilities using observed allele counts and an expected unique-mutation count distribution.

Inputs:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Observed allele-count table, read as gzipped CSV from `INPUT_DIR` | `AC_`, `Sites` |
| `UNIQUE_MUTATION_SITES_FILE` | Expected unique-mutation count distribution | `Unq muts sites` |

Optional input:

| Config | Description | Required columns |
| --- | --- | --- |
| `ERROR_FILE` | Error table used only when `APPLY_ERROR_CORRECTION = True` | `num_sites`, `error` |

Output:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Predicted SMFS probabilities. Columns: `Count`, `pred prob`. |

## Population Model Scripts

### `population_model/sample_site_mutation_rates.py`

Samples per-site mutation rates from mutation-rate metadata with mean and standard deviation values.

Input:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Mutation-rate metadata table, read as tab-separated text | `mean_theta`, `sd_theta`, `num_sites`, `mu_gnomad`, `methylation_level` |

The script also drops these columns if present in the input: `LL_no_heterogeneity`, `LL_heterogeneity`, `CV`, `LR`, `ref_context`, `alt_context`, `p_value`, `p_adj`.

Outputs:

| Config | Description |
| --- | --- |
| `EXPANDED_OUTPUT_FILE` | Expanded per-site sampled mutation-rate table. Columns: `Mutation number`, `Mutation rate`, `Mean theta`, `SD theta`, `Meth_level`, `Sampled mu`. |
| `DIAGNOSTIC_OUTPUT_FILE` | Metadata with sampled diagnostic means and standard deviations. Written only when `WRITE_DIAGNOSTIC_OUTPUT = True`. |

### `population_model/simulate_population_growth_mutations.py`

Simulates mutation accumulation through a growing population using sampled site-specific mutation rates.

Input:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Expanded per-site mutation-rate table, usually generated by `sample_site_mutation_rates.py` | `Mutation number`, `Mutation rate`, `Mean theta`, `SD theta`, `Meth_level`, `Sampled mu` |

Outputs:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Simulated mutation observations. Includes `Site`, mutation metadata, `Allele copies`, and `Mutation id`. |
| `MUTATION_RATE_OUTPUT_FILE` | Per-site mutation-rate table used in the simulation. Includes `Site` and mutation metadata. |

### `population_model/sample_observed_mutations.py`

Samples observed mutations from simulated allele-copy counts using a hypergeometric model.

Input:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Simulated mutation observations, usually generated by `simulate_population_growth_mutations.py` | `Allele copies` |

Output:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Sampled mutation table filtered to rows where `Sampled mutation` is nonzero. Adds the `Sampled mutation` column. |

### `population_model/summarize_derived_alleles_by_site.py`

Aggregates sampled mutation records by site.

Input:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Sampled mutation table, usually generated by `sample_observed_mutations.py` | `Site`, `Mutation id`, `Meth level`, `Mutation rate`, `Mutation number`, `Mean theta`, `SD theta`, `Sampled mu`, `Sampled mutation` |

Output:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Per-site derived-allele summary. Columns: `Mutation number`, `Site`, `Mutation rate`, `Mew theta`, `SD theta`, `Sampled mu`, `Meth level`, `Sampled mutation sum`, `Unique mutations`. |

### `population_model/fill_missing_simulation_sites.py`

Merges per-site derived-allele summaries back into the full mutation-rate table so sites with no observed sampled mutations are retained.

Inputs:

| Config | Description | Required columns |
| --- | --- | --- |
| `DERIVED_ALLELE_FILE` | Per-site summary, usually generated by `summarize_derived_alleles_by_site.py` | `Site`, `Sampled mutation sum`, `Unique mutations` |
| `MUTATION_RATE_FILE` | Full mutation-rate table, usually generated by `simulate_population_growth_mutations.py` | `Site` |

Output:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Merged simulation table with missing sampled values filled with zero. Renames `Sampled mutation sum` to `AC` and increments `Site` by 1. |

### `population_model/estimate_simulated_smfs_from_unique_mutations.py`

Numerically estimates predicted SMFS probabilities from simulated data and an expected unique-mutation count distribution.

Inputs:

| Config | Description | Required columns |
| --- | --- | --- |
| `INPUT_FILE` | Edited simulation data, usually generated by `fill_missing_simulation_sites.py` | `AC` |
| `UNIQUE_MUTATION_SITES_FILE` | Expected unique-mutation count distribution | `Unq muts sites` |

Output:

| Config | Description |
| --- | --- |
| `OUTPUT_FILE` | Predicted simulated SMFS probabilities. Columns: `Count`, `pred prob`. |
