# Publication Results

This directory retains selected result tables from the submitted manuscript and
the configuration describing the original publication analysis layout. These
files are reference artifacts, not the normalized example workflow.

## Files

| File | Description |
| --- | --- |
| `paper_config.toml` | Original publication settings, with the bundled mutation-rate reference path updated for this repository. |
| `lam_mu_josh.csv` | Fixed-mu xi estimate. |
| `lam_mu_sd_josh.csv` | Variable-mu xi estimate. |
| `sites_mut_events_mu.csv` | Fixed-mu expected unique-mutation site counts. |
| `sites_mut_events_mew_sd.csv` | Variable-mu expected unique-mutation site counts. |
| `smfs_num_300_josh_mu.csv` | Fixed-mu predicted SMFS probabilities. |
| `smfs_num_300_josh_mew_sd.csv` | Variable-mu predicted SMFS probabilities. |
| `all_sum_sites_mu_sd.csv` | Variable-mu diagnostic comparison table. |

Legacy filenames and column names are preserved so these tables remain
traceable to the publication analysis.
